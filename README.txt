STUDENT MANAGEMENT SYSTEM

Requirements:
- Python 3
- Internet connection for installing Flask

Run on Windows:
1. Extract the ZIP file.
2. Open Command Prompt or VS Code terminal inside the student_management folder.
3. Run: python -m pip install -r requirements.txt
4. Run: python app.py
5. Open http://127.0.0.1:5000 in your browser.

The students.db database is created automatically.
Keep the terminal open while using the application.

Note: This is a learning project. Do not expose Flask debug mode to the public internet.
